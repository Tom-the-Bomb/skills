# retrace

Learn how something was built by building it again yourself. Instead of reading a guide, you get the real problem the project solves, propose your own solutions, get pushed back on, and work your way to the actual design.

1. Real-world problem
2. Your solution
3. What breaks
4. Next problem

```
/retrace
/retrace the crawl queue
/retrace tanstack/query
```

Progress saves to `.retrace/` in the repo (git-excluded), so `/retrace` picks up where you left off.

Requires: `git`
